# Настройка магазина после обновления

Панель: `/nz-console`. Раздел владельца: **Документы и реквизиты**. Вход требует настроенного `AUTH_SECRET` (или ранее заданного `NEXTAUTH_SECRET`) и учётной записи администратора. Секреты не должны попадать в репозиторий. Для первичного создания владельца задайте `ADMIN_LOGIN` и собственный `ADMIN_PASSWORD` в Variables сервиса Railway. Общего пароля по умолчанию нет. Если ранее использовался пароль из старой инструкции, замените его своим.

## Что заполняет владелец

1. Полное наименование, ИНН, ОГРН/ОГРНИП, юридический адрес, адрес возврата, телефон, почту и режим работы. Для ИП — регистрирующий орган.
2. Реальные сроки и стоимость доставки, порядок оплаты и выдачи кассового чека. Текст на странице не подключает эквайринг, онлайн-кассу или ОФД. Текущая корзина оформляет заказ с оплатой наличными при получении.
3. Почту для запросов о персональных данных, фактическое место размещения базы, сведения о привлечённых обработчиках и сроки хранения по целям обработки.
4. В карточках товаров — изготовителя, место изготовления, импортёра/уполномоченную организацию, комплектацию, гарантийный срок, срок службы и сведения о подтверждении соответствия, когда применимо. Для этих данных предусмотрены описание и характеристики; сведения должны относиться к конкретному товару.

Поля не заменяют проверку фактической работы магазина. Если первичная база данных граждан РФ находится за рубежом, соответствующие приложение и данные необходимо разместить в РФ с учётом требований закона. Указание России в текстовом поле не переносит базу, резервные копии, файлы и журналы. Проверьте также используемые сервисы доставки, кассы и коммуникаций.

Оператору нужно проверить обязанность уведомления Роскомнадзора, договоры с обработчиками, сроки удаления и порядок исполнения запросов. Сайт не подаёт уведомления и не подтверждает организационные меры автоматически.

При передаче товара необходимо предоставить информацию о порядке и сроках возврата в письменном виде. Одна ссылка на страницу сайта не подтверждает её вручение покупателю.

## Редактор и публикация

Кнопка **Сохранить всё** сохраняет изменённые блоки, баннеры, преимущества и общие настройки одной транзакцией. Сохранение одного элемента не сбрасывает черновики остальных. При одновременном изменении одного элемента другим сотрудником публикация отклоняется без частичной записи. Основные блоки шаблонных страниц имеют закреплённое положение; дополнительные секции настраиваются отдельно.

Обновление добавляет таблицу `ConsentReceipt` и поле гостевого доступа в `SupportRequest`. Применяется обычной командой `npm run db:migrate`, без удаления таблиц или повторного seed. Существующая конфигурация Railway запускает миграции при старте. Используйте резервную копию PostgreSQL перед миграцией; при откате приложения дополнительные таблица и поле могут оставаться в базе.

Согласия на обработку данных в заказе, регистрации и новом обращении отделены от условий покупки и заранее не отмечены. Сохраняются цель, идентификатор заказа/аккаунта/обращения, дата, версия, точный текст и хеш документа. Изменение реквизитов меняет версию документов: старую открытую форму необходимо обновить. Рекламная подписка не подключена.

История поддержки доступна владельцу аккаунта, сотруднику с правами поддержки или по техническому cookie гостя. Старые гостевые обращения без такого cookie больше не открываются по одному номеру; сотрудник может найти их в панели. Старый гостевой заказ не привязывается к новому аккаунту только по введённому, неподтверждённому телефону.

## Правовая основа и проверка

- Закон РФ № 2300-1: [дистанционная продажа](https://www.consultant.ru/document/cons_doc_LAW_305/1525b1a2f037db240c8e6a749619f86e53857f13/), [недостатки товара](https://www.consultant.ru/document/cons_doc_LAW_305/76ae101b731ecc22467fd9f1f14cb9e2b8799026/), статьи 9–10; Правила продажи по постановлению № 2463.
- Закон № 152-ФЗ: статьи 6, 9, [18](https://www.consultant.ru/document/cons_doc_LAW_61801/cbf4e15b7c330f9372e876cdf2bc928bad7950ef/), 18.1, 22.
- Закон № 54-ФЗ: применение ККТ зависит от фактического способа расчёта.

Технические проверки без доступа к рабочим данным:

```sh
node scripts/test-auth.cjs
node scripts/test-store-overhaul.cjs
npm run build
```
